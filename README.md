# Datavisualization_facespeak
This project covers data processing workflows and a step-by-step data visualization pipeline. Every step is thoroughly commented, allowing you to adapt and use the modules as needed.
Please note that while sample data is provided in the files, it is for reference only. You must capture your own facial dynamic data and calculate the key metrics. This folder is solely meant for applying those key metrics to specific visual effects.
For reference images of the generated visual effects, please see the ref folder.
